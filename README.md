# 🚀 Looptask

Looptask is a role-based student freelancing platform that connects **Task Posters** with **Student Workers**.

Task Posters can create and manage tasks, while Student Workers can browse available opportunities and apply for them. The platform provides separate dashboards and features based on user roles.

---

## ✨ Features

### 🔐 Authentication
- User Signup
- User Login & Logout
- Supabase Authentication
- Secure session management

### 👤 Role-Based Access
- Student Worker Dashboard
- Task Poster Dashboard
- Dynamic navigation based on user role

### 📋 Task Management
- Create Tasks
- Browse Available Tasks
- View Posted Tasks
- Delete Tasks

### 📨 Application System
- Apply for Tasks
- Prevent Duplicate Applications
- View Applied Tasks
- View Applications Received

### 👤 Profile Management
- User Profile Page
- Displays Name, Email, and Role
- Professional Profile Card UI

### 🎨 User Experience
- Responsive Design
- Loading States
- Clean Dashboard Interface
- Role-Specific Features
